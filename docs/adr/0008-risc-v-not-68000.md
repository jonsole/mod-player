# The soft CPU is RISC-V (PicoRV32), not a 68000

An Amiga player might be expected to use a 68000 core, which would let it run the original ProTracker replay routine unmodified. We chose PicoRV32 instead. It is small and proven, written in Verilog that both ISE and Verilator handle, and permissively licensed. ProTracker accuracy comes from checking our C Replayer against pt2-clone (ADR-0007) rather than from running the original 68000 code.

## Considered Options

- **TG68K** (Minimig's core): proven, but VHDL, which Verilator cannot simulate, breaking the full-chip simulation plan (ADR-0005); LGPL.
- **ao68000**: Verilog, but less proven; LGPL.
- **fx68k**: cycle-exact, but SystemVerilog, which ISE's XST cannot build.
- All 68000 cores use several times PicoRV32's logic, leaving less room for HDMI, and the original replay source has no clear license for an MIT repo.
