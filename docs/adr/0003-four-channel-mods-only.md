# Version 1 plays only 4-channel, 31-sample MOD files

Paula has exactly four voices and the player accepts only 4-channel, 31-sample MOD files (M.K., M!K!, FLT4, 4CHN). This covers the large majority of Amiga Songs. Old 15-sample Soundtracker files and 6/8-channel PC MOD files are deliberately rejected for now; supporting them later means a Paula with more voices and a new loader path, not a tweak.
