# Match ProTracker 2.3, quirks and all, with no interpolation

The Replayer reproduces ProTracker 2.3 behaviour, including its known quirks, using the pt2-clone source as the reference; Paula outputs each sample unsmoothed, as the Amiga did. Modern players interpolate between samples for a cleaner sound, and a future reader may want to "fix" this; don't, because the target is how these Songs sounded on an Amiga.
