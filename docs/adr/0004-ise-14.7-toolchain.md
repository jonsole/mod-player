# Build with Xilinx ISE 14.7; write plain Verilog-2001

Spartan-6 is supported only by Xilinx ISE 14.7 (the free WebPACK covers the XC6SLX25); Vivado and the open-source flows do not target it. So the HDL is plain Verilog-2001 (chosen over VHDL to match the PicoRV32 core we reuse) that ISE's XST synthesiser accepts: no SystemVerilog, and memories written in styles XST can turn into block RAM. The FPGA build runs on the developer's machine via a command-line Makefile; cloud sessions can simulate but not build bitstreams.
